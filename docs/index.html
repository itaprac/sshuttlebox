Saved hosts

Organize SSH targets under short names with groups, identity files, and ports. Connect with one command.

shbx connect prod

Port tunnels

Local, remote, and SOCKS forwarding with persistent definitions. Start, stop, and watch status at a glance.

shbx tunnel start db

Shell completion

One-command install for bash, zsh, and fish. Autocomplete saved hosts and tunnels at the prompt.

shbx completion install
