From a host to a tunnel in three commands

  1. Save each host once

    Add a host by hand or pull every entry from ~/.ssh/config. After that, shbx connect prod is the whole command.

  2. Start a tunnel by its name

    Local, remote and SOCKS forwards run in the background through a saved host. shbx tunnel stop db ends one.

  3. Move files through the same host

    List, get and put files without typing the user, port or key again. shbx sftp prod opens a full session.

Small commands around your hosts. Checks, previews and completion.

Checks hosts, keys and tunnels

shbx doctor reads the config, the ssh binary, keys and tunnels. With --fix it clears stale tunnel state.

~zsh
$shbx doctor
config permissions: 0600
ssh binary: /usr/bin/ssh
saved hosts: 3
saved tunnels: 3
running tunnels: 1
Result: ok
$

Prints the SSH command first

Add --dry-run to connect, sftp or tunnel start and shbx prints the exact ssh line instead of running it.

~zsh
$shbx connect prod --dry-run
ssh -p 22 -i ~/.ssh/id_ed25519
-- deploy@192.0.2.10
$shbx tunnel start db --dry-run
ssh -p 22 -i ~/.ssh/id_ed25519
-o ExitOnForwardFailure=yes
-M -f -N -T -L 5432:127.0.0.1:5432
-- deploy@192.0.2.10

Completes host and tunnel names

One command installs completion for bash, zsh and fish, so Tab fills in every saved host and tunnel.

~zsh
$shbx completion install --shell all
Installed zsh completion: ~/.local/share/shbx/completions/zsh/_shbx
$shbx connect tab
jump prod staging
$shbx tunnel start tab
db grafana socks

Does sshuttlebox run on Windows?

No. It runs on macOS and Linux and calls the ssh and sftp you already have.

Where are my hosts stored?

In one JSON file at ~/.config/sshuttlebox/config.json. shbx config backup saves a copy of it.

Can I keep my ~/.ssh/config?

Yes. shbx import ssh-config reads its hosts; shbx export ssh-config writes them back.

Should I save SSH passwords in it?

Better not: they sit in the local config file. Use keys; shbx doctor flags hosts that still have one.

What does sshuttlebox cost?

Nothing. sshuttlebox is open source under the MIT licence.

Install sshuttlebox with Go

You need Go 1.22 or newer on macOS or Linux.

One command builds the shbx binary into ~/go/bin.

go install github.com/itaprac/sshuttlebox/cmd/shbx@latest
  • Put Go's bin folder on your PATHexport PATH="$HOME/go/bin:$PATH"
  • Or build it from the sourcego build -o shbx ./cmd/shbx
  • Then open the terminal UIshbx
~zsh
$go install github.com/itaprac/sshuttlebox/cmd/shbx@latest
$shbx config init
Created config: ~/.config/sshuttlebox/config.json
$shbx add prod --host 192.0.2.10 --user deploy
Added host "prod"
$shbx connect prod
Connecting to "prod" (deploy@192.0.2.10:22)...
